# GITEX Demo Explanation — VEHICLE-SUPRA

## Demo title

**VEHICLE-SUPRA Agent Coherence Recovery Simulation**

## One-line explanation

VEHICLE-SUPRA shows when an AI agent is losing coherence before failure propagates.

## What the demo shows

The demo uses a synthetic three-agent network:

1. `primary_agent` — the main autonomous AI decision agent.
2. `retrieval_agent` — a supporting knowledge/context agent.
3. `safety_agent` — a supervisory alignment/safety agent.

Each agent is represented as an E.I.A.R.(V) structured node:

- **E — Exposure:** contextual pressure or external load.
- **I — Integrity:** internal coherence and alignment.
- **A — Agency:** ability to act or execute.
- **R — Recovery:** ability to return toward coherence.
- **V — Value:** systemic importance of the node.

The simulation then injects stress into the primary agent and lets VEHICLE-SUPRA classify the agent's regime.

## Demonstration sequence

### Step 1 — A0 Stable Agent

The agent starts in stable coherent operation.

### Step 2 — A1 External Pressure

Context load increases. The agent is still internally coherent, but relational tension rises across the network.

### Step 3 — A3 Internal Incoherence

Conflicting or degraded instructions are injected. The agent enters an incoherent state before the whole system fails.

### Step 4 — Recovery

VEHICLE-SUPRA applies projection-governed recovery cycles to move the agent back toward an admissible coherent region.

### Step 5 — Twin-node continuity simulation

A coherent twin node is created from the last known-good reference state. This demonstrates continuity-preserving recovery in simulation.

## Important wording for public presentation

Use:

> This is an alpha research simulation showing how an AI agent can be modeled, monitored, classified, and guided toward recovery under VEHICLE-SUPRA.

Avoid saying:

> This does not guarantee production self-healing AI.

## Recommended GITEX presenter line

> VEHICLE-SUPRA gives AI agents a measurable coherence layer: it detects when they are drifting toward failure and activates structured recovery before the failure spreads.
