# Roadmap

## Current phase: v0.2 — research validation + GITEX preparation

Implemented:

- Structured node model with E.I.A.R.(V) five-dimensional state.
- Weighted relational network model G=(N,E).
- Internal tension T_int and external tension T_ext measurement.
- Projection-governed recovery step via V_op operator.
- A0–A6 regime classification with cascade detection.
- Twin-node recovery simulation for non-convergent nodes.
- Enterprise network example (12-agent simulation).
- GITEX 2026 single-agent coherence demo with timeline export.
- VEHICLE-LUNA lunar rover mission simulation (20 rovers, 3 scenarios).
- Unit tests: 8 passing.

## Next milestone: GITEX Global 2026 — December 8–10, Dubai

Target:

- VEHICLE-LUNA hardware validation path for Raspberry Pi / ESP32 rover demonstration.
- Real-time dashboard visualizing T(X) per rover.
- Live stand demo: crater fall, solar storm cascade, autonomous recovery.
- Expand North Star — Supernova Challenge participation.

## v0.3 — demonstration layer (post-GITEX)

Planned:

- Streamlit real-time dashboard.
- Prototype WebSocket API for optional Raspberry Pi / ESP32 rover control after hardware validation.
- Scenario library for public demonstrations.
- Reproducible Jupyter notebooks.
- Website-ready diagrams and documentation.

## Long-term direction

VEHICLE-SUPRA aims to become a research-grade architecture for
coherence-governed autonomous agent networks, validated across
multiple domains: enterprise AI, space exploration, epidemic
prioritization, food crisis allocation, and water governance.

Production claims will require formal testing, benchmarking,
safety analysis, and deployment-specific validation.
