# VEHICLE-SUPRA v0.2.1 — GITEX + LUNA Demonstration Release

VEHICLE-SUPRA v0.2.1 is an alpha research prototype release prepared for GitHub and GITEX 2026 demonstration workflows.

## Included

- Core VEHICLE-SUPRA Python prototype.
- E.I.A.R.(V) structured node model.
- SupraNetwork relational tension engine.
- A0-A6 regime classification.
- Projection-governed recovery simulation.
- GITEX AI-agent coherence demonstration.
- VEHICLE-LUNA lunar rover mission simulation.
- Sample JSON, Markdown, and console outputs.
- Initial tests and documentation.

## Demonstration narrative

The GITEX AI-agent demo shows:

1. A0 — stable coherent operation.
2. A1 — external pressure rising.
3. A3 — internal incoherence detected.
4. A2 — recovery in progress.
5. A0 — stable coherent operation restored.

The VEHICLE-LUNA demo models 20 lunar micro-rovers as VEHICLE-SUPRA nodes and demonstrates continuity-preserving recovery behavior under synthetic crater, solar storm, and mixed-crisis scenarios.

## Important disclaimer

This is an alpha research simulation. It is not a production uptime, robotics safety, autonomous reliability, or self-healing AI guarantee. Physical rover demonstrations should be described as planned or validated only after hardware testing is complete.
