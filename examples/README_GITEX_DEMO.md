# GITEX Agent Demo

Run from the repository root:

```bash
python examples/gitex_agent_demo.py
```

The script writes:

- `outputs/gitex_agent_demo_report.json`
- `outputs/gitex_agent_demo_report.md`
- `outputs/gitex_agent_demo_output.txt`

This is a synthetic alpha research simulation for public demonstration and technical validation.
